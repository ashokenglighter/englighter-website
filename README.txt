ENLIGHTER WEBSITE REBUILD
========================

Contents:
- index.html: Home
- learning.html: Learning pathways
- technology.html: Technology
- partners.html: Partner enquiries
- about.html: About Englighter and VQB Study Days Private Limited
- contact.html: Contact page (the enquiry number appears ONLY here)
- privacy.html: Privacy overview
- styles.css and script.js: shared design and interactions
- assets/: bundled image assets
- sitemap.xml and robots.txt: search-engine files

UPLOAD TO GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open https://github.com/ashokenglighter/englighter-website
3. Choose Add file > Upload files.
4. Upload the contents of this folder (not the ZIP and not the outer folder).
5. Commit directly to main. GitHub Pages will deploy automatically.

IMPORTANT NOTES
- The website enquiry number is intentionally shown only on contact.html.
- The contact form prepares a WhatsApp message; the visitor must review and send it.
- Confirm the public privacy wording against the actual application's data practices before relying on it as a legal privacy policy.
- The imagery is bundled locally in assets, so the website does not depend on remote image hosts.
